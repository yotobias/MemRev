## File formats in plain language

- **JSON (`.json`):** one structured document containing objects, lists and values. Our schemas define required fields; valid JSON syntax alone does not guarantee a valid research record.
- **JSONL (`.jsonl`):** one complete JSON object per line. The B export has one lesson per line, without a surrounding list.
- **CSV (`.csv`):** a table with a header and rows, used for task/target selection.
- **Markdown/text (`.md`, `.txt`):** instructions, prompts and readable reports.
- **ZIP / SHA-256 (`.zip`, `.sha256`):** portable package and its checksum. Manifests also record file hashes; these detect changed bytes, not whether a claim is true.

## One real example: SymPy printer inheritance

Open [the saved extraction](../runs/pilot-a/main-3/responses/sympy__sympy-16766/extraction.json). Its lesson advises inspecting the printer hierarchy before placing an indexed-expression handler in a shared base class. One assumption says:

> PythonCodePrinter directly inherits AbstractPythonCodePrinter.

This excerpt shows how the assumption points back to evidence; the full file contains the remaining schema fields:

```json
{
  "statement": "PythonCodePrinter directly inherits AbstractPythonCodePrinter.",
  "symbol": "PythonCodePrinter",
  "file": "sympy/printing/pycode.py",
  "evidence_message_indices": [4, 5],
  "evidence_basis": "code_observation",
  "workspace_context": "Original checkout before agent edits."
}
```

Its path through the workflow is:

1. **Trajectory:** recorded messages 4 and 5 contain the cited inspection. Indices refer to the original message list, not line numbers in a rendered prompt.
2. **Extraction:** the model records actionable advice and the specific inheritance assumption it relies on.
3. **Review:** AI review rates this assumption `usable_as_extracted`. That means no material extraction defect was identified; it is not a C0/C1 verdict.
4. **Repository check:** R could use the following illustrative check inside the verified task workspace. It has **not** been executed as part of this documentation:

   ```python
   from sympy.printing.pycode import AbstractPythonCodePrinter, PythonCodePrinter
   assert AbstractPythonCodePrinter in PythonCodePrinter.__bases__
   ```

   R must confirm the import resolves to the intended checkout. A passing assertion supports the direct-inheritance claim there; a failed assertion contradicts it there. An import/setup failure is inconclusive. Run at C0/C1; use Ca only if both contradict it.

5. **Return:** R records the observed results, workspace identity and private evidence hashes under this assumption's existing ID. N imports the return. The current cells remain pending until this happens.
6. **Sharing:** N determines whether another task's lesson relies on the same inheritance assumption under compatible scope. A second lesson mentioning printers is not automatically the same assumption.
7. **Report/export:** aggregate the verified findings and sharing counts. B receives the original advice and source/trajectory pointers, with A's analysis and limitations alongside it.
